# DESIGN.md: Portfolio Design System

## 1. Design Philosophy
- **Minimalism & Simplicity**: Clean typography, generous whitespace, and content-first layout.
- **Color Palette**: 
  - Light mode: Warm off-white background (`#faf8f5`), dark charcoal text (`#111110`).
  - Dark mode: Deep dark background (`#111110`), off-white text (`#e8e6e1`).
  - Accent color: Warm terracotta / rust (`#c4623a`).
- **Typography**: 
  - Sans-serif for body and headings.
  - Monospace for tags, dates, and code accents.

## 2. Layout Structure
- **Max Width**: `max-w-2xl mx-auto px-6` for optimal readability.
- **Navigation**: Minimal header with simple text links (Home, Now, Uses, Resume, Contact).
- **Footer**: Copyright and UTC+7 local time clock.
