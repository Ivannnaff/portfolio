# PRD: Portfolio Website (Ivan Akbar Alfahrezi)

## 1. Overview
A minimalist, high-performance personal portfolio website built with Astro and React, inspired by modern developer portfolios (such as up2dul.dev). It features a clean multi-page static architecture designed for zero friction deployment on Vercel.

## 2. Target Audience
Recruiters, engineering teams, and peers looking to view the developer's background, projects, skills, and contact information.

## 3. Core Features & Pages
- **Home (`/`)**: Introduction, developer branding, quick links, and featured work.
- **Now (`/now`)**: Current focus, learning goals, and activities.
- **Uses (`/uses`)**: Hardware, software, and tools used daily.
- **Resume (`/resume`)**: Professional experience, education, and skills list.
- **Contact (`/contact`)**: Clean social links and direct email.
- **404 Page (`/404`)**: Custom fallback page.

## 4. Technical Stack
- **Framework**: Astro (Static Output mode)
- **UI Components**: React & Tailwind CSS
- **Icons**: Lucide React
- **Deployment**: Vercel (Static Hosting)
